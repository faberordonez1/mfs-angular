# 4. Implementación de Lazy Load Interno y Nested Routes en Microfrontends

Esta guía documenta la optimización de `web-apuestas` y `web-recargas` mediante **Lazy Loading interno** y **rutas anidadas**, con rutas renombradas a inglés.

## 1. Objetivo

*   Mantener el componente `App` como vista por defecto (`/`) en cada microfrontend.
*   Cargar las funcionalidades principales en sub-rutas específicas (`/bets`, `/recharges`).
*   Implementar "Lazy Children" en rutas profundas.

## 2. Implementación en `web-apuestas`

### Estructura de Rutas
*   `/`:Landing del MFE (`App`).
*   `/bets`: Carga el módulo de `Apuestas`.
    *   `/bets/historial`: Carga `BetsHistoryComponent`.

### Ajustes de Código

**`src/app/app.routes.ts`**
Se corrigió la importación de `App` y se renombró la ruta a `bets`.
```typescript
{ path: '', component: App },
{ path: 'bets', loadChildren: () => import('./features/bets/bets.routes').then(m => m.BETS_ROUTES) }
```

**`src/app/features/bets/bets.routes.ts`**
```typescript
{ path: '', component: BetsComponent },
{ path: 'historial', loadComponent: () => import('./bets-history.component').then(m => m.BetsHistoryComponent) }
```

## 3. Implementación en `web-recargas`

### Estructura de Rutas
*   `/`: Landing del MFE (`App`).
*   `/recharges`: Carga el módulo de `Recargas`.
    *   `/recharges/actividad`: Carga `RechargeActivityComponent`.

### Ajustes de Código

**`src/app/app.routes.ts`**
Se corrigió la importación de `App` y se renombró la ruta a `recharges`.
```typescript
{ path: '', component: App },
{ path: 'recharges', loadChildren: () => import('./features/recharge/recharge.routes').then(m => m.RECHARGE_ROUTES) }
```

## 4. Navegación desde el Shell (`web-home`)

El menú principal del Shell ahora permite navegar directamente a los diferentes niveles de profundidad:

*   **Apuestas (MFE Root)**: `/apuestas`
    *   **Feature Bets**: `/apuestas/bets`
    *   **Historial**: `/apuestas/bets/historial`
*   **Recargas (MFE Root)**: `/recargas`
    *   **Feature Recharges**: `/recargas/recharges`
    *   **Actividad**: `/recargas/recharges/actividad`
