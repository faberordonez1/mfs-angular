# 🧩 Guía: Configurar Module Federation en Angular 20

Esta guía convierte tres aplicaciones Angular en una arquitectura **microfrontend** usando **Module Federation** nativo.

## 🔧 Estructura final

| Proyecto | Tipo | Contexto / Base Href | Puerto (dev) |
|-----------|------|----------------------|---------------|
| `web-home` | Shell (host) | `/` | 4201 |
| `web-apuestas` | Remote | `/apuestas/` | 4202 |
| `web-recargas` | Remote | `/recargas/` | 4203 |

---

## 1️⃣ Instalar dependencias necesarias

En cada proyecto (shell y remotes):

```bash
npm install @angular-architects/module-federation --save-dev
```

## 2️⃣ Generar configuración base con el CLI
Shell (host)
```bash
npx @angular-architects/module-federation init --project web-home --port 4201
```

Remotes
```bash
npx @angular-architects/module-federation init --project web-apuestas --port 4202
npx @angular-architects/module-federation init --project web-recargas --port 4203
```
Esto crea los archivos base:

* `webpack.config.js`
* `src/bootstrap.ts`
* Modifica `main.ts`


## 3️⃣ Ajustar los remotes (apuestas / recargas)
`📁 web-apuestas/webpack.config.js`

```js
const { withModuleFederationPlugin } = require('@angular-architects/module-federation/webpack');
const path = require('path');

module.exports = withModuleFederationPlugin({
  name: 'web_apuestas',
  exposes: {
    './Module': './src/app/app.module.ts',
  },
  filename: 'remoteEntry.js',
  shared: {
    '@angular/core': { singleton: true, strictVersion: true },
    '@angular/common': { singleton: true, strictVersion: true },
    '@angular/router': { singleton: true, strictVersion: true },
  },
  // ⚙️ Public path dinámico (para Docker/WAF)
  output: {
    publicPath: process.env.PUBLIC_PATH || 'auto',
    uniqueName: 'web_apuestas',
  },
});
```

`📁 web-recargas/webpack.config.js`

## 4️⃣ Ajustar el Shell (Host)
`📁 web-home/webpack.config.js`

Aquí se mezcla configuración dinámica y manual.

```js
const { withModuleFederationPlugin } = require('@angular-architects/module-federation/webpack');
const dotenv = require('dotenv');
dotenv.config(); // Carga variables desde .env

module.exports = withModuleFederationPlugin({
  remotes: {
    web_apuestas: `web_apuestas@${process.env.REMOTE_APUESTAS_URL || 'http://localhost:4202'}/remoteEntry.js`,
    web_recargas: `web_recargas@${process.env.REMOTE_RECARGAS_URL || 'http://localhost:4203'}/remoteEntry.js`,
  },
  shared: {
    '@angular/core': { singleton: true, strictVersion: true },
    '@angular/common': { singleton: true, strictVersion: true },
    '@angular/router': { singleton: true, strictVersion: true },
  },
  output: {
    publicPath: process.env.PUBLIC_PATH || 'auto',
    uniqueName: 'web_home',
  },
});
```

## 5️⃣ Configurar las rutas dinámicas del Shell

`📄 web-home/src/app/app-routing.module.ts`

```js
import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { loadRemoteModule } from '@angular-architects/module-federation';

const routes: Routes = [
  {
    path: 'apuestas',
    loadChildren: () =>
      loadRemoteModule({
        type: 'module',
        remoteEntry: `${(window as any).__remotes__?.web_apuestas || 'http://localhost:4202'}/remoteEntry.js`,
        exposedModule: './Module',
      }).then(m => m.AppModule),
  },
  {
    path: 'recargas',
    loadChildren: () =>
      loadRemoteModule({
        type: 'module',
        remoteEntry: `${(window as any).__remotes__?.web_recargas || 'http://localhost:4203'}/remoteEntry.js`,
        exposedModule: './Module',
      }).then(m => m.AppModule),
  },
  { path: '', redirectTo: '', pathMatch: 'full' },
];

@NgModule({
  imports: [RouterModule.forRoot(routes)],
  exports: [RouterModule],
})
export class AppRoutingModule {}
```
